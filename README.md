SCSMS – Smart Civic Service Management System

A full-stack web application designed to streamline civic issue reporting and resolution.
The platform enables users to report problems, track status, and interact with authorities efficiently.

⸻

Features

* Report civic issues (roads, waste, water, etc.)
* Track complaint status in real-time
* User authentication and secure access
* Interactive frontend with responsive UI
* REST API integration between frontend and backend

⸻

Tech Stack

Frontend: HTML, CSS, JavaScript
Backend: Node.js, Express.js
Database: MongoDB (if used)
Others: Python (AI module), REST APIs

⸻

Project Structure

backend/ → Server-side logic
frontend/ → UI and client-side code
civic-ai/ → AI-related features

⸻

Setup Instructions

1. Clone the repository
    git clone https://github.com/your-username/SCSMS-new
2. Navigate to project directory
    cd SCSMS-new
3. Install dependencies
    npm install
4. Start the server
    npm start
